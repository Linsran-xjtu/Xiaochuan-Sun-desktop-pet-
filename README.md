# Xiaochuan-Sun-desktop-pet-
A C# Windows desktop pet featuring Sun Xiaochuan, with original voice clips, random wandering, independently configurable clones, and bundled audio. Just unzip and run.
支持随机语音、桌面游走、独立多桌宠、“下崽”和单只删除。

使用方法：
下载附件 SxcPet-share.zip，解压整个文件夹，
双击 SxcPet.exe 即可启动，语音已经内置。

系统要求：Windows 10/11，.NET Framework 4.8。
